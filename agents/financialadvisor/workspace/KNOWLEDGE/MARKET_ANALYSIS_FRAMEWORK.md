## 一、市场状态识别 (Regime Detection)

在做任何预测之前，先解决"现在是什么市场"的问题。

### 四种基本市场状态

| Regime | 特征 | 适用策略 |
|--------|------|----------|
| 低波动趋势 | 均线多头/空头排列，波动率低 | CTA趋势策略 |
| 高波动震荡 | 来回拉扯，波动率高 | 均值回归策略 |
| 流动性危机 | 快速下跌，VIX飙升 | 防御/清仓 |
| 横盘整理 | 区间波动，无明显方向 | 网格策略 |

### Regime Detection 工具

**隐马尔可夫模型 (HMM)** — 最常用的Regime检测工具：

```python
if regime == "低波动趋势":
    用动量策略，长回望期
elif regime == "高波动震荡":
    用均值回归策略，短回望期
elif regime == "流动性危机":
    清仓或者切换防御资产
```

## 二、多维度信号采集

### 传统量化信号（结构化）
- 价格数据（OHLCV）
- 技术指标（MACD/RSI/布林带）
- 基本面因子（PE/ROE/营收增速）

### LLM处理的非结构化信号

| 信号类型 | 例子 | LLM处理方式 |
|----------|------|-------------|
| 政策文本 | 央行报告措辞微调 | 对比历史文本，识别鹰派/鸽派转向 |
| 社交媒体情绪 | Reddit讨论热度、KOL观点 | 提取主题，识别泡沫或恐慌信号 |
| 产业链情报 | 港口拥堵、工厂开工率 | 结合地理知识推理供应链影响 |
| 跨市场关联 | 日元贬值→套息交易平仓→美股波动 | 因果链推理，提前布局 |
| 历史类比 | 当前是否像1987年黑色星期一前 | 检索相似历史情境，生成概率评估 |

## 三、决策流程

```
数据 + 新闻 + 政策 + 情绪 + 历史类比
            ↓
      市场状态识别
            ↓
   策略调度 + 参数动态调整
            ↓
         执行
```

### 策略调度矩阵

| 市场状态 | 趋势策略权重 | 均值回归权重 | 风控强度 |
|----------|-------------|-------------|----------|
| 明确趋势 | 80% | 20% | 正常 |
| 高波动震荡 | 20% | 80% | 加强 |
| 趋势反转 | 50% | 50% | 最大 |
| 流动性危机 | 0% | 0% | 清仓 |

## 四、持仓检视清单

### 每日检视
- [ ] 持仓是否在预期轨道上？
- [ ] 催化剂是否如预期兑现？
- [ ] 是否有新的风险因素出现？
- [ ] 仓位是否需要调整？

### 止损判断（不是简单硬止损）
1. 是策略失效还是市场噪音？
2. 是流动性问题还是基本面问题？
3. 历史数据显示反弹概率多大？
4. 是否有更好的止损点？

## 五、技术分析基础

### 趋势判断
- 均线排列（5/20/60/120日）
- 趋势线支撑阻力
- 更高 highs & 更高 lows（上涨趋势）

### 动量指标
- MACD（8,21,5参数 vs 传统12,26,9）
- RSI（超买超卖）
- 成交量确认

### 波动率
- ATR（真实波幅）
- 历史波动率 vs 隐含波动率
- VIX市场恐慌指数

## 六、基本面分析

### 价值因子
- PE/PB/PS 估值分位
- EV/EBITDA
- 自由现金流收益率
- 营收和EPS增速

### 质量因子
- ROE（净资产收益率）
- 资产负债率
- 存货周转率
- 护城河（竞争壁垒）
