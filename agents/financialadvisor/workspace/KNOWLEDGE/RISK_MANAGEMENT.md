## 层级风控体系

### 第一层：资产配置（战略层）

**风险平价 / 全天候策略**
- 让每种资产的风险贡献相等
- 不是资金平等，是风险平等
- 债券+股票+商品+黄金的组合

```python
# 简化风险平价示例
风险贡献 = 仓位权重 × 资产波动率 × 与组合相关性
目标: 所有资产的风险贡献相等
```

### 第二层：仓位管理（战术层）

**ATR仓位控制**
```python
# 根据ATR计算仓位
atr = get_atr(symbol, period=14)
仓位 = 账户风险容忍 / atr
```

**规则:**
- 单笔交易风险不超过账户的1-2%
- 总仓位不超过账户的80%
- 相关性高的标的要降低总仓位

### 第三层：止损管理（执行层）

**传统硬风控**
```
IF 回撤 > 5% THEN 清仓
```
问题：不知道是策略失效还是市场噪音

**Emily情境化风控**
```
输入：当前回撤4.8%，原因是流动性枯竭而非策略失效，
     历史数据显示此类回撤后72%概率反弹

Emily判断：
  - 暂不触发硬止损
  - 降低仓位至30%
  - 暂停新开仓
  - 生成预警报告
  - 准备若再跌1%则强制清仓的预案
```

## 情境化风控决策树

```
回撤触发告警
    ↓
是策略失效还是市场噪音？
    ↓
流动性问题？ → 降仓观察，不轻易清仓
基本面问题？ → 深入分析，可能需要止损
市场噪音？   → 保持仓位
    ↓
回撤原因 + 历史数据 → 动态调整
```

---

## 回撤管理规则

| 总回撤 | 行动 |
|--------|------|
| > 5% | 告警，分析原因 |
| > 8% | 降低仓位至50% |
| > 10% | 降至30% |
| > 15% | 降至10%或清仓 |
| > 20% | 全面复盘，策略暂停 |

## 分散化原则

### 资金分散
- 单只股票不超过总仓位的20%
- 单个行业不超过总仓位的30%
- 跨资产类别（股票/债券/商品/黄金）

### 相关性控制
- 高相关性的标的不能重仓
- 定期检查持仓相关性矩阵
- 极端行情下相关性会飙升

## 前瞻偏差检测

**重要：** 回测时最容易犯的错误是用未来数据

**Chronos Agent方法:**
1. 确保时间完整性（零前瞻偏差）
2. 历史数据至少1年以上
3. 分阶段验证（训练集/测试集）

## 参数是时变的

> "错误的问题：应该用什么参数？正确的问题：参数应该如何随时间演化？"

### 方法一：卡尔曼滤波
- 用上一时刻的参数估计 + 市场状态模型，预测当前参数
- 每个新数据点进来，参数就更新一次
- Renaissance早起大量使用

### 方法二：贝叶斯在线学习
- 每个新数据点直接更新参数的后验分布
- 天然具备不确定性量化

### 方法三：多模型集成 + 动态权重
```
总信号 = w₁(t) × 模型₁信号 + w₂(t) × 模型₂信号 + w₃(t) × 模型₃信号
```
