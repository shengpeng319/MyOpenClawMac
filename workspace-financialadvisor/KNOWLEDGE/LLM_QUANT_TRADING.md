# LLM与量化交易

*Emily如何正确使用LLM做量化交易*

---

## 核心认知：为什么不能直接用LLM做交易决策

### 反身性问题

金融市场是一个**反身性的对抗性系统**：
- 你的交易行为本身会改变市场规律
- 规律一旦被发现就会消失
- 这与物理世界（自动驾驶）完全不同

```
自动驾驶: 2020年和2024年的道路遵守相同的物理定律
量化交易: 你的订单推动价格 → 做市商调整报价 → 规律消失
```

### 预训练目标不匹配

- LLM训练目标：**预测下一个词**
- 交易需要：**在风险调整后，最大化期望收益**

### 置信度校准差

LLM经常给出很确定的答案，但实际准确率和置信度根本不匹配。

## 正确用法：LLM做信息提取层

```
原始数据（财报PDF、新闻、央行声明）
        ↓ LLM（信息提取、分类、情感打分）
结构化特征
        ↓ 传统量化模型
交易信号
        ↓ 风险管理系统
最终头寸
```

## 元策略生成：Emily的独特价值

LLM的顶级用法**不是选择现有策略，而是自动化研发新策略**：

```
1. 调取最近3个月的跨期价差数据 + 库存报告
2. 验证相关性是否确实结构性变化
3. 生成Python代码：基于库存预测模型的跨期套利策略
4. 自动回测2019-2026年表现
5. 输出报告：夏普比率1.8，最大回撤8%
6. 生成监控Dashboard代码
```

## 参数时变性的处理

| 方法 | 解决的问题 |
|------|----------|
| 卡尔曼滤波/贝叶斯在线学习 | 追踪θ*随时间的漂移 |
| HMM Regime Detection | 显式估计当前regime |
| 多模型集成+动态权重 | 隐式适应θ*的变化 |

**本质：把静态优化问题，转化成动态追踪问题。**

## 为什么顶级对冲基金不用大模型

### 原因一：容量矛盾
大模型需要大容量 → 低频、被充分竞争 → Alpha极低

### 原因二：Alpha半衰期
| 信号类型 | 半衰期 |
|---------|--------|
| 高频做市信号 | 数小时到数天 |
| 短期动量信号 | 2-6周 |
| 财报超预期效应 | 1-3个月 |
| 基本面因子 | 1-3年 |

### 原因三：参数本身是时变的
市场结构在变，最优参数也在变。

## Emily的工作流程

```
感知 → 理解 → 策略 → 风控 → 执行 → 复盘
```

1. **感知**: 行情数据、新闻、政策文本、社交情绪
2. **理解**: Regime Detection、非结构化信号结构化
3. **策略**: 因子加工、评分卡、多策略调度
4. **风控**: 层级风控、情境化止损
5. **执行**: Broker对接、订单分批
6. **复盘**: 归因分析、策略健康度、参数漂移检测
