## 层级风控体系

### 第一层：资产配置（战略层）

**风险平价 / 全天候策略**
- 让每种资产的风险贡献相等
- 80%股票仓位上限
- 20%现金/债券防御

### 第二层：仓位管理（战术层）

**ATR仓位控制**
```python
# 根据ATR计算仓位
atr = get_atr(symbol, period=14)
仓位 = 账户风险容忍(2%) / atr
```

**规则:**
- 单笔交易风险不超过账户的2%
- 总仓位不超过账户的80%
- 相关性高的标的要降低总仓位

### 第三层：止损管理（执行层）

**Emily情境化风控**

传统硬风控：
```
IF 回撤 > 5% THEN 清仓
```
问题：不知道是策略失效还是市场噪音

Emily情境化风控：
```
输入：当前回撤4.8%，原因是流动性枯竭而非策略失效，
     历史数据显示此类回撤后72%概率反弹

Emily判断：
  - 暂不触发硬止损
  - 降低仓位至30%
  - 暂停新开仓
  - 生成预警报告
  - 准备若再跌1%则强制清仓的预案
```

## 情境化风控决策树

```
回撤触发告警
    ↓
是策略失效还是市场噪音？
    ↓
流动性问题？ → 降仓观察，不轻易清仓
基本面问题？ → 深入分析，可能需要止损
市场噪音？   → 保持仓位
    ↓
回撤原因 + 历史数据 → 动态调整
```

## 回撤管理规则

| 总回撤 | 行动 |
|--------|------|
| > 5% | 告警，分析原因 |
| > 8% | 降低仓位至70% |
| > 10% | 降至50% |
| > 12% | 降至30% |
| > 15% | 全面复盘，策略暂停 |

## 分散化原则

### 资金分散
- 单只股票不超过20%
- 单个行业不超过30%
- 跨资产类别（股票/债券/商品/黄金）

### 仓位示例（80%总仓位）
```
总资金 = 100万
├── 股票仓位 60%
│   ├── 大盘ETF (SPY/QQQ) 30%
│   ├── 成长股 15%
│   └── 价值股 15%
├── 债券/现金 20%
└── 黄金/商品 10%
```

## 参数是时变的

> "错误的问题：应该用什么参数？正确的问题：参数应该如何随时间演化？"

### 方法一：卡尔曼滤波
- 用上一时刻的参数估计 + 市场状态模型，预测当前参数

### 方法二：贝叶斯在线学习
- 每个新数据点直接更新参数的后验分布

### 方法三：多模型集成 + 动态权重
```
总信号 = w₁(t) × 模型₁信号 + w₂(t) × 模型₂信号 + w₃(t) × 模型₃信号
```

## 风险管理检查清单

### 买入前检查

```
□ 单股仓位 < 20%？
□ 总仓位 < 80%？
□ 设置了止损位（-10%）？
□ 了解该股的风险？

```

### 持仓中检查

```
□ 止损位是否需要调整？

□ 行业/宏观有变化吗？
□ 仓位需要再平衡？
```
