## 进化报告发送失败分析（22:20）

### 失败现象
cron session 状态：`stopReason: aborted`，报告未发出

### 根因
1. **sessions.send 对大消息不稳定**：2000+ 字的消息体，JSON 转义链路长，gateway 直接 abort
2. **Feishu API content 格式错误**：直接传原始文本，报 `230001 content is not a string in json format`
3. **没有降级方案**：消息大了就挂，没有切小或换方法

### 解决方案（已验证）
1. 大段文字/报告先写文件，再用飞书 API 直发
2. Feishu text 消息的 `content` 格式必须是 `json.dumps({"text": text_content})`

### 固化要点
- 大消息（>500字）直接用飞书 API，不走 sessions.send
- sessions.send 只用于小消息（<500字）
