## classmgr Service 局域网配置

**问题**：Mac 重启后 classmgr frontend 没有开机自启，且 vite dev server 默认只监听 localhost
**解决**：
1. 手动 `launchctl load` 加载 plist
2. vite.config.ts 加 `server: { host: '0.0.0.0', port: 5173 }`
3. launchd 已有 RunAtLoad=true，下次重启应自动加载

**Frontend**：http://192.168.101.50:5173/classmgr/
**Server**：http://localhost:3000
